# Terra Bioware 

![Terra Bioware Logo](https://terra-bioware.vercel.app/logo.png)

> **Climate-Positive Biomanufacturing · Est. 2022, Bengaluru**

**Terra Bioware** (Anava Bioware Pvt. Ltd.) engineers proprietary methanotrophic microbes that capture industrial methane and CO₂, transforming them into **TerraPHA** — a family of 150+ high-performance, marine-biodegradable biopolymers for packaging, medicine, and agriculture.

---

## 🌍 The Mission
The world is drowning in plastic and choking on methane. Conventional plastics persist for centuries, and existing biodegradable alternatives are prohibitively expensive. Meanwhile, industrial methane — a greenhouse gas 80× more potent than CO₂ — is mostly wasted. 

**Our Solution:** We capture methane directly at the source and convert it into high-value biopolymers. Our process is net-negative at production scale: every kilogram of PHA produced removes greenhouse gases from the atmosphere.

**The TerraPHA Process:**
1. **Methane Capture:** Capturing industrial CH₄ + CO₂ directly from the source (landfills, wastewater, oil & gas).
2. **Microbial Bioreactors:** Utilizing proprietary methanotrophs (Methylocystis, Methylosinus) to metabolize methane into PHAs.
3. **PHA Extraction & Processing:** Producing 1 kg of biodegradable PHA from every 2-3 kg of methane.

---

## 🔬 Material Properties
TerraPHA biopolyesters rival conventional petroleum-based plastics with unparalleled sustainable properties:
- 💧 **Marine Biodegradable:** Decomposes safely in ocean environments without leaving microplastics.
- 🌱 **Home Compostable:** Breaks down in backyard compost conditions (soil, moisture, time).
- 🍃 **Carbon Negative:** Sequesters more greenhouse gas equivalents than emitted during production.

## 🚀 Market Applications (One Polymer, Infinite Uses)
- **Nutraceuticals & Pharma:** Drug delivery systems, capsule shells.
- **Cosmetics & Personal Care:** Microplastic-free exfoliants, bio-based packaging, microspheres.
- **Medical Devices:** Bioabsorbable sutures, tissue engineering scaffolds.
- **Sustainable Packaging:** Flexible films, rigid containers, coatings.
- **Agriculture:** Biodegradable mulch films, seed coatings, controlled-release fertilizers.
- **Manufacturing:** 3D printing biodegradable filaments.
- **Consumer Products:** Single-use truly home-compostable products.

## 💻 Tech Stack (Web Platform)

This repository contains the codebase for the Terra Bioware web platform (deployed at [terra-bioware.vercel.app](https://terra-bioware.vercel.app/)), built with a modern and highly interactive technology stack:

### Framework & Core
- **[Next.js](https://nextjs.org/) (v14)**: React framework with App Router.
- **[React](https://reactjs.org/) (v18)**: UI Library.
- **[TypeScript](https://www.typescriptlang.org/)**: Type-safe development.

### Styling & Animation
- **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework.
- **[Framer Motion](https://www.framer.com/motion/)** & **[GSAP](https://gsap.com/)**: Powerful and complex UI animations.
- **[@studio-freight/react-lenis](https://github.com/studio-freight/react-lenis)**: Smooth scroll experiences.
- **[Three.js](https://threejs.org/)** & **[React Three Fiber](https://docs.pmnd.rs/react-three-fiber)**: For advanced 3D web graphics and rendering.

### State & Forms
- **[Zustand](https://github.com/pmndrs/zustand)**: Lightweight global state management.
- **[React Hook Form](https://react-hook-form.com/)** & **[Zod](https://zod.dev/)**: Form handling and schema validation.

### Backend & Integrations
- **[Supabase](https://supabase.com/)**: Open source Firebase alternative for database and backend services.

## 🛠 Getting Started

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd terra-bioware
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   Create a `.env.local` file and add necessary environment keys (e.g., Supabase keys).

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
